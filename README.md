# 특허사무소 무료진단 랜딩페이지 리뉴얼 — 데이터 분석

한 줄 요약: 특허사무소 무료진단 신청이 2020년 308건에서 2022년 72건으로 줄었다. 줄어든 원인을 방문과 신청률로 나눠 찾고, 리뉴얼 사이트와 광고 조정을 내놓았다.

공개 URL: https://mindain.github.io/patent-landing-analysis/

## 1. 문제 정의
- 대상과 문제: 특허를 알아보는 개인·중소기업이 쓰는 무료진단 사이트의 신청이 2020년 308건에서 2022년 72건으로 줄고 회복되지 않았다.
- 비즈니스 임팩트: 연 약 200건 감소 × 수임률 10~20% × 출원 수수료 약 300만 원 = 연 약 6,000만~1.2억 원.
- 성공 기준: 신청 연 150건. 방문당 신청률이 2020년 수준(4.6%)으로 돌아오면 지금 방문(2024년 3,812)으로 177건이 나온다.
- 지표 식: 총 매출 = 수임당 매출 × 수임 전환율 × 방문당 신청률 × 방문수. Focus 지표는 방문당 신청률.

## 2. 데이터
사무소 내부 자료라 원본은 올리지 않고, 집계값만 공개한다.

| 데이터 | 기간 | 행 수 | 전처리 |
|---|---|---|---|
| 신청 알림 문자 | 2014-11 ~ 2026-10-05 | 2,895 | 스팸 254건 제외 |
| 신청 게시판 | 2014 ~ 2026 | 2,174 → 2,141 | 스팸 10건, 잘못된 번호 23건 제외 |
| 서버 관리자 접속자통계 | 2015 ~ 2026-10-06 | 연도별 합계 | OS가 Robot·Linux인 방문을 봇으로 보고 제외 |
| 네이버 검색광고 검색어 보고서 | 2026-07-06 ~ 10-03 | 27,277 | 보고서 제목 줄 제거 |

## 3. 분석과 검증
리포트 본문(index.html)에 주장마다 차트와 수치를 붙였다.
- 신청 감소 236건 = 방문 감소 47% + 방문당 신청률 감소 53% (셰이플리 분해)
- 포괄 검색어 9개('특허'·'변리사' 등)가 광고비 26%를 쓰지만 클릭률 0.06%, 구체적 검색어 0.50% (피셔 정확검정, p<0.001)

## 4. 해결책
| 누가 | 무엇을 | 움직이는 지표 |
|---|---|---|
| 나(개발) | 새 사이트(글자·첫 화면 신청 칸·분쟁 페이지) 완성, 변리사 확인 후 공개 | 방문당 신청률 |
| 나(개발) | 포괄 검색어 입찰 낮추기, 제외 키워드 | 광고 클릭률, 광고비 |
| 나(개발) | 네이버 광고 신청 추적 켜기 | 검색어별 신청 |
| 변리사 | 신청마다 수임 여부 기록 | 수임 전환율 |

- 사용자 확인: 특허사무소 변리사가 리포트를 읽고 action item을 반영하겠다고 답했다.

## 5. 한계
경로별 감소 원인은 추정이다. 서버 통계는 연도 합계뿐이다. 신청 뒤(전화·수임) 데이터가 없다. 광고는 클릭까지만 본다.
