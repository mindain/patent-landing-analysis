# 특허사무소 무료진단 랜딩페이지 리뉴얼 — 데이터 분석

한 줄 요약: 특허사무소 무료진단 신청이 2020년 308건에서 2022년 72건으로 줄었다. 줄어든 원인을 방문과 신청률로 나눠 찾고, 리뉴얼 사이트와 광고 조정을 내놓았다.

공개 URL: https://mindain.github.io/patent-landing-analysis/
발표 슬라이드(브라우저에서 바로 넘기기): https://mindain.github.io/patent-landing-analysis/slides.html

## 1. 문제 정의
- 대상과 문제: 특허를 알아보는 개인·중소기업이 쓰는 무료진단 사이트의 신청이 2020년 308건에서 2022년 72건으로 줄고 회복되지 않았다.
- 비즈니스 임팩트: 연 약 200건 감소 × 수임률 10\~20% × 출원 수수료 약 300만 원 = 연 약 6,000만\~1.2억 원.
- 성공 기준: 신청 연 150건. 방문당 신청률이 2020년 수준(4.6%)으로 돌아오면 지금 방문(2024년 3,812)으로 177건이 나온다.
- 지표 식: 총 매출 = 수임당 매출 × 수임 전환율 × 방문당 신청률 × 방문수. Focus 지표는 방문당 신청률.

## 3. 분석과 검증
리포트 본문(index.html)에 주장마다 차트와 수치를 붙였다. 사실은 데이터로 센 것, 해석은 "추정"이라고 표시했다.

**신청 감소의 분해 (2장)**
- 사실: 신청 308건(2020) → 72건(2022). 같은 기간 방문 6,648 → 3,397, 방문당 신청률 4.6% → 2.1%.
- 검증: 셰이플리 분해로 줄어든 236건을 방문 몫 47%, 신청률 몫 53%로 나눴다. 떼는 순서에 따라 36\~71%라 평균을 썼다.

**방문: 어디서 줄었나 (1장)**

| 경로 | 2020 → 2022 | 원인 |
|---|---|---|
| 다음 | 644 → 7 (−99%) | 다음 광고·등록 중단 (변리사 확인) |
| 네이버 블로그 | 600 → 43 (−93%) | 글 수는 그대로(2020·21년 318·322건). 글 형태 변화와 네이버 노출 방식 변화로 추정 |
| 네이버 검색 | 2,220 → 1,028 (−54%) | 사이트 글자가 모두 그림이라 검색에 안 잡힘 + 네이버 개편으로 추정 |
| 네이버 광고 | 472 → 283 (−40%) | 가장 덜 줄어 원인 아님. 지금은 실제 방문의 3분의 2 |

**광고 검색어 (1-6)**
- 포괄 검색어 8개('특허'·'변리사' 등)가 노출 68%, 광고비 26%를 쓰지만 클릭률은 0.06%(78/133,105). 구체적 검색어는 0.50%(309/61,748)다. 피셔 정확검정에서 우연일 확률 0.1% 미만.
- 포괄 검색어를 빼고 비교하면 직접 등록한 키워드 0.61%(209/34,453), 확장검색 0.32%(81/25,588). 같은 검정에서 우연일 확률 0.1% 미만.
- 지역명 검색어가 일반 검색어보다 자주 눌린다. 피셔 정확검정에서 우연일 확률 0.1% 미만.
- 광고비를 45% 줄였을 때 신청은 18건에서 15건이 됐다. 이항검정으로는 차이라 보기 어렵고(73%), 포아송 검정으로는 광고비만큼 줄지 않은 경향(8%)이다.

**방문당 신청률 (2-2)**
- 광고로 온 120세션의 머문 시간 중앙값은 18초이고, 27%가 5초 안에 나갔다(GA4).
- Clarity 녹화 5건 중 4건은 20\~34초 읽고 신청하지 않았다.

**수임 전환율과 수임당 매출 (3·4장)**
- 수임 여부 기록이 없다. 신청의 81%가 번호만 남기는 간편 신청이고, 주말 신청이 적다(z 검정, 우연일 확률 0.1% 미만).
- 분쟁은 신청의 6%지만 수수료가 출원의 약 7배(2,000만 원 대 300만 원)다.

## 4. 해결책
| 어느 분석에서 | 누가 | 무엇을 | 움직이는 지표 |
|---|---|---|---|
| 1-2 다음 −99% | 변리사 | 다음(카카오) 광고·등록 재개 검토. 2020년 수준이면 연 약 30건. 비용은 카카오 광고 단가 확인 뒤 | 다음 방문 |
| 1-3 블로그 −93% | 변리사 | 실적 나열 대신 읽을 내용이 있는 글로 | 블로그 방문 |
| 1-4 네이버 검색 −54%, 2-2 18초 | 나(개발) | 새 사이트: 글자를 텍스트로, 18초 안에 "누가·무엇을·무료로", 첫 화면과 글 끝에 간편 신청, 휴대폰 대응. 변리사 확인 뒤 공개 | 방문당 신청률, 네이버 검색 방문 |
| 1-6 포괄 검색어·확장검색 | 변리사(광고 직접 관리) | 포괄 검색어 입찰 낮추기·제외, 확장검색은 성적 나쁜 그룹부터 끄기, 엉뚱한 검색어 제외 | 광고 클릭률, 광고비 |
| 1-6 지역명 검색어 | 변리사 | 지방 키워드 늘리기 | 광고 클릭 |
| 4-1 분쟁 수수료 7배 | 나(개발) | 분쟁 전용 페이지(폼보다 전화) | 분쟁 신청 |
| 3-1 수임 기록 없음 | 변리사 | 신청마다 수임 여부 기록(분기 1회), 네이버 전환 추적(신청함, 승인 뒤 설치) | 수임 전환율, 검색어별 신청 |

- 사용자 확인: 특허사무소 변리사가 리포트를 읽고 action item을 반영하겠다고 답했다.

## 5. 한계
경로별 감소 원인은 추정이다. 서버 통계에서 경로별 방문은 연도 합계뿐이다. 신청 뒤(전화·수임) 데이터가 없다. 광고는 클릭까지만 본다. 수임률·수수료는 기록이 아닌 변리사 기억에 의한 대략의 값이다.

## 6. 실행법과 폴더 구조

```
analysis/
  stats.mjs              검정(피셔·이항·포아송·z) → analysis/data/stats_table.md
  charts.mjs             리포트 차트 → portfolio/charts/*.svg
  md2html.mjs            리포트 md → html
  make_final_slides.mjs  발표 슬라이드 5장 → portfolio/final-slides.pptx
portfolio/
  report.md              리포트 원문
  charts/                리포트 차트
index.html, charts/      공개 페이지(GitHub Pages). portfolio/report.md를 html로 바꾼 것
slides.pptx, slides.pdf  발표 슬라이드 5장
slides.html, slides/     브라우저 발표용(클릭·방향키로 넘김, F 전체 화면)
```

Node.js 18 이상에서 저장소 루트에서 실행한다.

```
npm install
npm run stats     # 검정 결과표
npm run charts    # 차트
npm run report    # 리포트 html
npm run slides    # 슬라이드
```

원자료(신청 문자·게시판, 서버 통계, 광고 보고서)는 사무소 내부 자료라 올리지 않았다. 스크립트에는 원자료에서 집계한 값이 들어 있어 원자료 없이도 같은 결과가 나온다.
